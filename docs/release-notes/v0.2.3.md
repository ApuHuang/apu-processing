APU Processing 0.2.3：**有新版會提醒**。處理結果跟 0.2.2 完全一樣。

## 下載

| 系統 | 檔案 |
|---|---|
| Windows 10 / 11（64 位元） | `APUProcessing-0.2.3-win64.zip` |
| Mac（Apple M 系列晶片） | `APUProcessing-0.2.3-macos-arm64.zip` |
| Mac（Intel 處理器） | `APUProcessing-0.2.3-macos-x86_64.zip` |

解壓後的資料夾裡有 `Quick-Start.txt`（使用說明）。第一次開啟被系統擋下的處理方式見 [README](https://github.com/ApuHuang/apu-processing#下載)。

## 新功能

- **新版本提醒**：有新版時，頂部版號旁邊會出現藍色的「↓ 新版」，按一下用瀏覽器下載你這台電腦對應的檔案。
  沒有新版時什麼都不會出現。程式不會自己下載或更新，下載一樣經過瀏覽器，系統原本的安全提示照常出現
- **怎麼檢查**：程式開啟時連到 GitHub 查最新版本，一天最多一次；只查版本號、不送任何個人資料；沒網路也不影響使用
- **「說明」選單**：可以取消「開啟時檢查新版本」，也可以直接開下載頁面
- 頂部的檔名太長時，改成從後面截掉加「…」（以前會兩頭被切掉）

> 從這一版開始才有提醒：0.2.2 以前的版本不會知道有新版，這次請手動更新。

## 已知限制

- 還沒疊圖、也還沒解拜耳的彩色相機單張原始檔會被當成單色影像處理，請先疊圖再開
- 其他同 0.2.2：Windows 處理速度約 Mac M 系列的一半、Windows 上滾輪縮放稍卡

**English**

APU Processing 0.2.3: **tells you when a new version is out**. Processing results are identical to 0.2.2.

Downloads: `APUProcessing-0.2.3-win64.zip` (Windows 10/11, 64-bit), `-macos-arm64.zip` (Apple silicon), `-macos-x86_64.zip` (Intel Mac). Each includes `Quick-Start.txt`.

**New**
- **New-version notice**: when a newer release exists, a blue "↓ New" badge appears next to the version number at the top; click it to download the file for your computer in your browser. Nothing appears otherwise. The app never downloads or updates itself, so the usual system security prompts still apply.
- **How it checks**: at startup the app asks GitHub for the latest version, at most once a day. Only the version number is fetched and no personal data is sent; it works offline too.
- **Help menu**: turn off "Check for New Versions at Startup" or open the download page.
- Long file names at the top are now cut with an ellipsis instead of being clipped at both ends.

The notice starts with this version: 0.2.2 and earlier cannot tell you about updates, so please update manually this time.

**Known limitations**: unstacked raw frames from color cameras are treated as mono, so stack them first. Otherwise as in 0.2.2.
