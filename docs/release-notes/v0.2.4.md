APU Processing 0.2.4：**給 APU Astro Studio 用的公開介面**，修一個量噪聲的錯誤。處理結果跟 0.2.3 完全一樣。

## 下載

| 系統 | 檔案 |
|---|---|
| Windows 10 / 11（64 位元） | `APUProcessing-0.2.4-win64.zip` |
| Mac（Apple M 系列晶片） | `APUProcessing-0.2.4-macos-arm64.zip` |
| Mac（Intel 處理器） | `APUProcessing-0.2.4-macos-x86_64.zip` |

解壓後的資料夾裡有 `Quick-Start.txt`（使用說明）。第一次開啟被系統擋下的處理方式見 [README](https://github.com/ApuHuang/apu-processing#下載)。

## 改了什麼

- **修正**：用某些縮小倍率（例如 3 倍）量拉伸用的噪聲時會出錯。APU Processing 自己的快速預覽只用 2、4、8 倍，
  不會遇到；整合版 APU Astro Studio 會。0.2.3 的倍率算出來的結果一個像素都沒變
- **給開發者**：新增 `apu_processing.api`，列出 APU Astro Studio 可以使用的函式；另外把找星用的噪聲量法獨立成
  `detail.fine_noise`（找星的結果不變）。APU Astro Studio 每次更新會用固定的小圖檢查這些函式的輸出有沒有變

## 已知限制

- 同 0.2.3

**English**

APU Processing 0.2.4: **a public interface for APU Astro Studio** and a fix to noise measurement. Processing results are identical to 0.2.3.

Downloads: `APUProcessing-0.2.4-win64.zip` (Windows 10/11, 64-bit), `-macos-arm64.zip` (Apple silicon), `-macos-x86_64.zip` (Intel Mac). Each includes `Quick-Start.txt`.

**Changes**
- **Fix**: measuring the stretch noise on a preview reduced by some factors (for example 3×) raised an error. APU Processing's own quick preview only uses 2×, 4× and 8× and never hit it; APU Astro Studio did. At the factors 0.2.3 uses, results are unchanged to the pixel.
- **For developers**: new `apu_processing.api` module listing the functions APU Astro Studio may use; the star-detection noise estimate is now its own function, `detail.fine_noise` (star detection is unchanged). APU Astro Studio checks the output of these functions against fixed small images on every update.

**Known limitations**: same as 0.2.3.
