## 改進

- **星點與背景分開處理**：降噪只作用在背景上，星點不再被磨軟、核心保持明亮；星點邊緣的噪聲毛邊也清掉了
- **拉長的星點變圓**：追蹤或導星讓整張星點往同一個方向拉長時，縮星會順便把星點修圓（以前反而會更扁）
- **天空的大片斑駁變少、淡星雲保留更多**：降噪以前把暗塵、淡星雲這類淡淡的大尺度結構誤當成噪聲，一塊一塊抹掉，看起來像斑駁；
  現在量噪聲的方式改了，淡結構會留下來
- **暗星保留更多**：降噪改成看周圍一小塊一起判斷，孤立的噪聲點會去掉，暗星（一小團都比噪聲亮）會留下來
- 多濾鏡合成時，頂部的檔名太長會被切掉 → 共同的開頭只寫一次

這次的降噪是用同一組單張拆成「少的一份」與「多的一份」各自疊圖，拿多的那份當真實答案來量的，不是對照別的軟體的成品。

## 已知限制

- 天空背景偏暗的地方，暗的噪聲點比亮的明顯，放大看像細小的黑點（拉伸曲線的關係，下一版處理）
- 星點變圓是用整張一個平均的形狀：畫面各處拉長方向不同時（例如鏡片傾斜），邊角的星還會留一點
- 還沒疊圖、也還沒解拜耳的彩色相機單張原始檔會被當成單色影像處理，請先疊圖再開
- 其他同 0.2.1：Windows 處理速度約 Mac M 系列的一半、Windows 上滾輪縮放稍卡

**English**

APU Processing 0.2.2: **cleaner noise reduction, rounder and crisper stars**. The interface is unchanged and images are still processed automatically when opened.

Downloads: `APUProcessing-0.2.2-win64.zip` (Windows 10/11, 64-bit), `-macos-arm64.zip` (Apple silicon), `-macos-x86_64.zip` (Intel Mac). Each includes `Quick-Start.txt`.

**Improved**
- **Stars and background are processed separately**: noise reduction only touches the background, so stars are no longer softened and their cores stay bright; the noisy fringe around stars is cleaned up.
- **Elongated stars become round**: when tracking or guiding stretches all stars the same way, star reduction now rounds them (before, it made them flatter).
- **Less blotchy sky, more faint nebulosity kept**: noise reduction used to mistake faint large-scale structure such as dust for noise and wipe it out in patches; the noise is now measured differently so faint structure survives.
- **More faint stars kept**: noise reduction now judges each spot together with its neighbours, so isolated noise specks go while faint stars stay.
- Long file names in the combine view are shortened (the common prefix is shown once).

The noise reduction was measured against real data: the same subframes split into a small and a large stack, with the large stack as the answer. No other software's output was used as a reference.

**Known limitations**: in dark sky areas, dark noise specks stand out more than bright ones (a property of the stretch curve; next release). Star rounding uses one average shape for the whole frame, so if the elongation changes across the field (e.g. tilt) corner stars may stay slightly elongated. Unstacked raw frames from color cameras are treated as mono, so stack them first. Otherwise as in 0.2.1.
